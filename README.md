# N-Takım

N-Takım; TEKNOFEST ve benzeri teknoloji yarışmalarına katılmak
isteyen kullanıcıların yetkinliklerini doğrulayan ve onları proje
ihtiyaçlarına göre uygun takımlarla eşleştiren yapay zekâ destekli
bir takım geliştirme platformudur.

## Temel Özellikler

- Kullanıcı profili oluşturma
- Yetkinlik ekleme ve doğrulama
- Gemini API ile yapay zekâ destekli yetenek testi
- Takım ilanı oluşturma
- Açıklanabilir takım ve proje önerileri
- Uyum puanı hesaplama
- Takıma başvuru ve çalışma uyumu formu
- Mesajlaşma ve takvim yönetimi

## Kullanılan Teknolojiler

- TypeScript 5.9.3
- React 19.2.6
- Vite 8
- Vinext
- Gemini API
